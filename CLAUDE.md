# Working agreement for this repo

## Commit attribution — ask, never assume

Do **not** add `Co-Authored-By:`, `Claude-Session:`, `Generated with...` or any
other AI-attribution trailer to commits or PR descriptions in this repo by default.

If you believe a commit warrants attribution, **ask me first and wait for an
answer.** Do not add it and then mention it afterwards.

This is deliberate: the repo is a public portfolio artifact, and I want to decide
case by case what appears in its history. A `commit-msg` hook strips these
trailers automatically, so adding them will silently fail anyway.

## What this repo is

A single self-contained `index.html` publishing the Physical AI Market Map to
GitHub Pages. There is no build step.

- **Source of truth is not this repo.** `index.html` is generated by wrapping
  `Brain/output/physical_ai_market_map_artifact.html` (an artifact fragment with
  no doctype/head/body) in a standalone document shell. Edit the artifact, then
  regenerate. Editing `index.html` directly will be overwritten.
- **Run `python validate.py index.html` before every commit.** It parses the
  embedded company data and asserts the invariants the map claims about itself:
  counts quoted in prose against the data, controlled vocabularies, filter
  vocabularies covering the values actually present, layer resolution, and
  business-model/maturity coverage. It must exit clean.
- **The map's credibility rests on prose matching data.** If you change a
  number in the data, find every place the prose states it. If you change a
  filter's vocabulary, check nothing becomes unreachable.

## Editing conventions

- Type sizes come from the `--fs-*` scale. Do not set `font-size` in raw px.
- Colours come from the theme tokens. Both light and dark themes must be
  checked; `--ink` and `--hi` swap roles between them.
- Anything asserted as fact needs a source. Classifications and judgements are
  labelled as such in Method, and new ones must be too.
